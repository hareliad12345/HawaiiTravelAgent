# HawaiiTravelAgent 🌺🌋

הבית של הטיול להוואי (24.11–6.12.2026). כל סשן עם Claude קורא מכאן ומעדכן לכאן.

| קובץ | מה יש בו |
|---|---|
| `trip/profile.md` | מי אנחנו, מה אוהבים / לא אוהבים |
| `trip/itinerary.md` | תוכנית יום-יום |
| `trip/backlog.md` | מאגר אטרקציות ורעיונות לפי אי ואזור |
| `trip/bookings.md` | טיסות, לינה, רכב, הזמנות ורזרבציות שצריך לתפוס |
| `trip/feedback-log.md` | מה אהבנו / לא – משמש לדיוק ההמלצות |
| `context/` | קבצי הקשר שמעלים (צ'אטים קודמים, ייצוא Google Maps, טיולים קודמים) |
